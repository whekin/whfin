# Редизайн формы счёта и карты — 29 сентября 2026

## Наблюдение

Первый снимок TBC показывал большую группу выбора банковского продукта,
длинное объяснение и карту как тревожное предупреждение. Найденные четыре цифры
оказывались далеко ниже по форме, физический и виртуальный типы с «позже»
переносились на разные строки при RU/font 1.5. Контекст счёта обозначался только
общим «Счёт», а поле добавления карты занимало место до уже найденных карт.

## Изменение

- Заголовок называет последние цифры договора и валюты. Найденные карты идут
  первыми; банковский продукт и название/IBAN доступны ниже в раскрывающихся
  строках. Роль средств остаётся отдельным видимым выбором.
- Неизвестный тип обозначается выбранным «Позже», без цвета ошибки. При выборе
  физического или виртуального типа появляется независимое действие «Основная».
  Если тип снова отложить, прежний выбор основной карты очищается.
- Тип карты и четыре банковских продукта выбираются горизонтальной прокруткой
  в один ряд. На узком экране виден край следующего варианта с мягким затуханием;
  ранее выбранный тип показывается при открытии. Кнопки не переносятся.
- Поле для дополнительных четырёх цифр раскрывается по «Добавить ещё карту»,
  когда у договора уже есть найденные карты. QA-сцена показывает модальную форму
  поверх настоящего шага настройки, чтобы визуальная проверка имела контекст.

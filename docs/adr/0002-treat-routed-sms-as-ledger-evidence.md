# Treat routed SMS as active ledger evidence

A routed supported-bank SMS becomes an ordinary active ledger transaction immediately; `SMS` is its
provenance, not a pending review status. Statements remain the stronger evidence and later reconcile,
enrich, or correct that row silently. We accept that an SMS row may be temporarily less complete because
requiring routine confirmation would make the owner maintain the tracker instead of the tracker serving
the owner; only missing routing remains an explicit decision.

# Установка WHFIN 0.3.70 (82) на Galaxy S25 — 28 сентября 2026

По прямой просьбе владельца обновлён Samsung Galaxy S25 (`SM-S931B`) через
`adb install -r`. Приложение не удалялось; `pm clear`, тесты на телефоне,
восстановление и ручной запуск после установки не выполнялись. Личная база
не читалась.

Перед установкой на телефоне была версия 0.3.69 (81), APK SHA-256
`6b6d7e5226849c9b1bf522c9ed848c8ad615e5e75eede7f463ae326230a14cf6`.
Текущему релизу назначены 0.3.70 (82), так как `docs/release-signing.md`
требует новый versionCode для следующего APK. Release `assembleRelease`
успешен с R8 и lintVital.

До установки сертификат старого APK и нового релиза совпал:
`af600982905fc962f57c0507f7042c5dbfe23ada4ca677c55495ccd6752fae92`.
После установки `base.apk` телефона совпал с собранным релизом по SHA-256:
`9b88c9091bbe9bc07660c7c83ddb6cae9eb64068d2835174c657501d6c33c704`.
Телефон сообщает `versionCode=82`, `versionName=0.3.70`.

`firstInstallTime` остался `2026-08-16 19:13:46`. Разрешения `READ_SMS`,
`RECEIVE_SMS` и `POST_NOTIFICATIONS` **до и после** обновления имели
`granted=false`; установка их не включала. Активного `BankSyncService` перед
установкой не было. В последних записях `AndroidRuntime:E` и `WHFIN:E`
после обновления ошибок нет. Схема Room остаётся v8. Живой банковский вход,
SMS-доставка и визуальная проверка на личных данных этим проходом не запускались.

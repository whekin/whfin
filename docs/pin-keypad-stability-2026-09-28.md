# PIN: неподвижная цифровая клавиатура

## Причина

`WhfinPinPad` центрировал заголовок, подсказку, точки, сообщение об ошибке и сетку цифр как одну колонку. При переходе «Создай код» → «Повтори код» подсказка становилась короче и вся колонка меняла положение. На Pixel_9_Pro AVD верхний ряд клавиатуры сдвигался на 33 px в EN и на 47 px в RU/font 1.5. Host-тест без настоящего окна Android не воспроизвёл этот дефект; инструментальная проверка реальных координат воспроизвела его в обеих конфигурациях.

## Исправление

Сетка цифр получила отдельную измеряемую зону, поэтому длина текста над ней больше не меняет её координаты. На компактном экране верхняя часть может прокручиваться, а клавиатура остаётся на месте. Для сообщения об ошибке зарезервирована постоянная высота с учётом font scale: две строки RU больше не перекрывают верхний ряд цифр. Компактный заголовок расходует меньше места.

## Проверка

- Pixel_9_Pro AVD: создание → повтор → несовпадение в EN/light, RU/dark/font 1.5 и RU/dark/font 1.5 при 1200×1920; положение кнопки «1» одинаково внутри каждого маршрута. Отдельно проверена ошибка разблокировки.
- Скриншоты до: `/tmp/whfin-pin-before-2026-09-28/`; после: `/tmp/whfin-pin-final-qa/`. Финальный компактный кадр с правильным контрастом системных значков: `/tmp/whfin-pin-compact-verified.png`.
- Полный host-прогон: 1229 тестов, 0 failures/errors, 5 skipped. Release R8/lintVital прошли. `WhfinNumericKeypad` и проверка самого PIN не менялись.

На личном S25 инструментальные тесты не запускались. Разбор SMS из предыдущего этапа остаётся отдельным вопросом и требует явного согласия на чтение и временное сохранение текстов сообщений.

# Завершение SMS-сверки и 0.3.81 — 30.09.2026

## Результат

После первого исправления оставались четыре сообщения из длинной очереди
Bank SMS. Они теперь сопоставляются автоматически: две покупки — по точной
исходной сумме/валюте и допустимым вариантам descriptor, два повторных собственных
перевода — как полный набор. На полном приватном повторе **0 ожиданий**:
155 сообщений прикреплены к банковским строкам, 2 имеют `MATCHED_GROUP`,
2 отменены. Весь денежный ledger до и после совпал.

## Правила

Карточная сверка читает исходные деньги из подтверждённого банковского
описания Credo и проверяет другие валютные ledgers только внутри известного
договора карты. Amazon marketplace и retail имеют отдельные узкие семейства
описаний. Alias требует точной суммы/валюты и единственного кандидата; неверная
сумма, другой договор, повторные кандидаты или общее похожее название не
разрешаются молча. Merchant/category memory не переписывается.

Для неразличимых собственных переводов проверяется равное количество SMS
и банковских списаний, точные день, валюта, сумма и оба IBAN, полная получающая
сторона каждой банковской группы. Занятые источники и ручной `OWN_LINK`
не участвуют. `MATCHED_GROUP` подтверждает весь набор, не назначая SMS
конкретной строке. Сами денежные строки, категории и группы не изменяются.
Подтверждённые источники резервируются от отдельного матчинга. Изменившийся
банковский набор возвращает весь SMS-набор к сверке; оставшаяся строка
не выбирает произвольное сообщение. Подробный контракт: ADR 0003.

В Bank SMS результат находится в недавней активности, с галочкой и просмотром
оригинала, без предложения выбора счёта. Русская подпись сокращена до
«Сопоставлено группой» для полного чтения на компактном экране при font 1.5.
Схема Room остаётся v8: новое enum-значение использует существующий TEXT-столбец.
SMS journal по-прежнему исключён из portable backup; секреты не добавляются.

## Проверка

- Три новые положительные регрессии сначала упали на прежнем коде.
  Семнадцать публичных проверок settlement evidence теперь включают alias,
  original money, неоднозначность и изменение банковской multiplicity.
- Полный host-прогон: 1293 теста, 0 failures/errors, 5 skipped.
- Настоящие restore/import/batch paths на приватной in-memory копии:
  весь ledger совпал и все 20 прежних ожиданий исчезли.
- Отдельно воспроизведены исходы установленной 0.3.80, без таблицы SMS в backup.
  Сверка сохранённой очереди исправила 20 сообщений без чтения Inbox;
  следующий проход изменил 0. Денежный ledger также полностью совпал.
- Новый результат проверяется на Pixel_9_Pro: EN/light и RU/dark/font 1.5,
  компактный 1200×1920 экран. Первый install на AVD отказал из-за недостатка
  места; тесты увидели старый debug APK. Повторный install прошёл, версия
  0.3.81 (93) сверена перед повтором тестов. Инструментация только адресная,
  физический S25 не использовался для тестов.
- Подписанный release и финальный визуальный повтор после сокращения RU-текста
  ещё проверяются.

Приватный backup, SMS, снимки физического телефона и диагностические snapshots
хранились вне репозитория с ограниченным доступом и удалены после проверки.
Временный replay-код удалён; публичные fixtures синтетические.

## Установка

Готовится адресное обновление S25 с 0.3.80 (92) на 0.3.81 (93) через `install -r`.
Перед установкой проверяются отсутствие BankSyncService, подпись, версия и наличие
restorable backup. После установки — версия, SHA-256 base.apk, прежняя дата первой
установки, SMS/notification permissions и неизменность backup в Downloads.
